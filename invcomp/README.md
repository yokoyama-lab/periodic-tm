# invcomp — 対合コンパイラ（プロトタイプ）

位数有限（局所有限）の可逆プログラム P を、**2つの対合プログラム**の
合成 I1 ∘ I2 にコンパイルする変換の最小実装。

```bash
python3 invcomp.py   # 3例（位数3・位数6・合成プログラム）で全検査
```

- 意味論的正当性の根拠は局所有限分解定理
  （`../lean/FiniteOrderTM/LocallyFinite.lean`、sorry ゼロ）。
  本実装はその構成（軌道走査・最小元基点・反射）をプログラム変換として
  実装し、生成物の対合性と合成の一致を全状態で機械検査する。
- 出力 I1, I2 は同一ミニ言語の AST（`reflect[i1](P)` / `reflect[i2](P)`）。
  P をブラックボックスのサブルーチンとして呼ぶため、**P の中身を
  解析せずに**分解できるのが特徴（分解定理の効果性そのもの）。

## 新規性（2026-07-29 サーベイ済み）

「位数有限の可逆プログラム → 2対合の合成」というプログラム変換、
およびその機械検証は先行なし。Nakano の ITM（RC 2020）3部作の
被引用は計8件で、コンパイル・変換系の研究はゼロ。最接近は
Gajardo–Kari–Moreira（JCSS 2012、CA の時間対称分解の可否）と
Nakano SCP 2022（時間対称 CA = 2対合の合成、の観察）だが、
どちらも構成的変換・機械検証を持たない。must-cite リストと
詳細な差分は研究ノート側に記録。

## ITM バックエンド（2026-07-29 追加）

`itm_backend.py` — コンパイルした対合プログラムを themes/04 の
四つ組形式の機械に落とし、3層で機械検査する。

1. **構文的対合性**: 規則集合の Lecerf 反転が、状態の対合的リネーム σ
   でちょうど元に戻ること（Nakano の ITM 対称性のプロトタイプ版。
   σ の全探索は所属判定の決定手続きになっており、予想 1.0 の条件 (M)
   の n = 2 での実例でもある）。両例で σ = {q0 ↔ halt}、すなわち
   「機械が自分自身の逆再生と一致する」ことが確認できる。
2. **機械意味論の対合性**: 各 Mi を2回走らせると恒等。
3. **直列合成**: M1 → M2 の機械実行が P の意味論に一致。

これでパイプライン P → (I1, I2) → (M1, M2) が末端（機械の遷移表）
まで通り、各段が機械検査つきになった。残るは文字列エンコード
（1マス → I/O 規約）と、この検査手続き自体の Lean 化。

## 対象言語の決定と可逆 reflect（2026-07-29 追加）

- **対象言語は RFCL/SRL に決定**（`yokoyama-lab/RFCL`）。理由は
  (1) 横山–Axelsen–Glück の自前フレームワークで PRO の物語に直結、
  (2) インタプリタ・インバータ・静的検査器・Bennett 変換・可逆
  デバッガが実装済み、(3) **SRL↔Janus 双方向変換が既にある**ため
  SRL で作れば Janus フロントエンドが無料で付く（両言語で競う必要が
  消えた）。
- `reflect_reversible.py` — reflect のインプレース可逆実装。
  ι = ι⁻¹ を使う標準トリック（Bennett 2回 + swap）で
  (x,0,[]) → (ι(x),0,[]) を実現し、全マイクロステップの単射性・
  逆再生可能性・補助領域のクリーン性・直列合成 = P を機械検査
  （2例、全通過）。残作業2（可逆実装）はこれで原理実証済み。
  次は同じ構成を SRL プログラムとして出力すること。
