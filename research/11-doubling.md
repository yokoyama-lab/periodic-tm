# 定理 11.1（鏡映複製）— 免疫横断性は強可逆性を妨げない（問Aのクラス版の解決）

Higman (1990, p.143) は自身の免疫横断置換 ρ について「ρ⁻¹ と共役か
どうか分からない」と記した。定理 7.2 は対合共役子の側から
「固定鎖は有限本」という制約を与えたが、残った逃げ道（全鎖の対交換）
が**実際に実現可能**であることが分かった。すなわち:

## 定理 11.1

**全横断集合が免疫であり、かつ計算可能な反転対合を持つ計算可能置換
ρ̂ ∈ C₀ ∩ R が存在する。**

したがって「全横断集合が免疫」という性質は、逆元との（対合による）
共役可能性を**どちらにも決めない**:
- Higman の第2構成の ρ は逆元と共役でない（定理 3.7(ii)）。
- 本定理の ρ̂ は対合で逆元と共役。
- どちらのクラスの元も横断集合の性質だけでは区別できない
  （ρ̂ は免疫、第2構成の免疫性は主張されていないが、
  第1構成 ρ と ρ̂ は同じ「免疫横断」クラスに属する）。

## 構成（鏡映複製）

ρ₀ を Higman の定理 3.1 の免疫横断置換とする（C₀ ∩ R、全鎖無限）。
台を N × {0, 1}（計算可能な対で N と同一視）とし、

  ρ̂(x, 0) = (ρ₀(x), 0),  ρ̂(x, 1) = (ρ₀⁻¹(x), 1),  ι(x, i) = (x, 1−i).

- ρ̂, ι は計算可能（ρ₀⁻¹ も計算可能）。ι² = id。
- ι ρ̂ ι = ρ̂⁻¹: 面 0 で ι ρ̂ ι (x,0) = ι ρ̂ (x,1) = ι(ρ₀⁻¹x, 1) =
  (ρ₀⁻¹x, 0) = ρ̂⁻¹(x,0)。面 1 も対称。∎（機械検査: doubling_check.py）
- ρ̂ ∈ C₀: 鎖は各面に ρ₀ の鎖のコピー（面1は向き逆）で、無限本・
  有限鎖なし。ι は各鎖を反対面の鏡像鎖へ写す（固定鎖ゼロ —
  定理 7.2 の「固定は有限本」と整合し、その限界が最良であることを示す）。

## 免疫性の証明

Higman p.147 の言い換え「全横断集合が免疫 ⟺ 任意の無限 c.e. 集合が
同一サイクルに 2 点を含む」を使う。X ⊆ N × {0,1} を無限 c.e. とする。
X の面 0 への痕跡 X₀ = {x : (x,0) ∈ X} と面 1 への痕跡 X₁ の少なくとも
一方は無限で、どちらも c.e.。X₀ が無限なら ρ₀ の免疫性より x, y ∈ X₀
が同じ ρ₀-サイクルにあり、(x,0), (y,0) は同じ ρ̂-サイクル（面 0 の
サイクル分割は ρ₀ と同一）。X₁ が無限の場合も同様（面 1 のサイクル
分割も ρ₀ と同一。向きが逆なだけで台集合は同じ）。∎

## 帰結と残る問い

1. **定理 7.2 は最良**: 反転対合は固定鎖有限本を強制するが、
   全対交換は排除できない — 実例があるから。
2. **Higman の問い（p.143）の正確な残り**: 彼の**特定の** ρ（定理 3.1
   の機械構成そのもの）が ρ⁻¹ と共役か。クラスレベルでは両方の
   可能性が実現するので、答は構成の詳細（M の統制の仕方）に依存する。
   おそらく ρ 自体は複製対称性を持たないので非共役と予想するが、
   証明には定理 3.6 型の要件を定理 3.1 の構成に織り込む必要がある
   （両構成の要件は衝突しないように見える — 統合構成が次の一手）。
3. **問B（特徴づけ）の再定式化**: 強可逆性は軌道の複雑さ
   （横断集合の次数・免疫性）では決まらない。決めるのは
   「鎖どうしの計算可能な鏡映対称性の有無」という**大域的な対称性
   構造**である。特徴づけ候補: ρ が強可逆 ⟺ 鎖の対合的ペアリング
   π と、各対の計算可能な逆向きアラインメントの一様な族が存在する
   （これはほぼ定義の言い換えだが、「一様な族」を横断集合の言葉に
   落とせるかが問題）。

機械検査: `doubling_check.py`（ι²=id・ιρ̂ι=ρ̂⁻¹・固定鎖ゼロを
9970 点で確認、全通過）。
