# 問B/問C: 可逆から強可逆への矯正 — 半シフト補正定理

問C「R で可逆（∃計算可能 g: g f g⁻¹ = f⁻¹）⟹ 強可逆（対合でとれる）か」
への最初の実質的な部分回答。強可逆性の特徴づけ（問B）の座標もここで定まる。

## 定理 13.1（半シフト補正）— 証明済み

f を計算可能置換、g を f の計算可能な reverser（g f g⁻¹ = f⁻¹）とし、
**g の軌道空間への作用 γ が対合**（すべての f-軌道 C で g(g(C)) = C）
だとする。このとき f は強可逆であり、対合的 reverser ι は g から
一様に計算できる。

**証明.** g² は f と可換（g² f g⁻² = f）で、仮定より各軌道を保つので、
無限鎖 C 上では g²|_C = f^{t(C)}|_C なる整数シフト t(C) が定まる。
t(C) は C の任意の点 x から計算可能: t = 0, ±1, ±2, … を試して
f^t(x) = g²(x) となる t を探せば必ず停止する。

*シフトの反対称性.* C' = g(C) とすると、g g² g⁻¹ = g² を C' 上で
評価して f^{−t(C)}|_{C'} = g²|_{C'}、すなわち **t(C') = −t(C)**。
特に γ の固定軌道では g|_C が向き反転なので t(C) = 0。

*補正.* 軌道ごとのシフト s(C) := −⌈t(C)/2⌉ を使い

  ι(x) := g( f^{s(C(x))}(x) )

と定める（s は t から計算可能）。ι²(x) を計算すると、
x ∈ C, ι(x) ∈ C' に対し ι²(x) = f^{s(C) − s(C') + t(C)}(x)。
整数恒等式 −⌈t/2⌉ + ⌈−t/2⌉ = −t（機械検査済み）より指数は 0、
すなわち ι² = id。また ι f ι⁻¹ = f⁻¹ は g のそれと軌道ごとの
f-巾の挿入が可換なことから保たれる。有限軌道は定理 4.1 の
軌道内反射で処理（g 不要）。∎

機械検査: `reverser_correction.py` — 恒等式と、シフト付き鏡映対の
トイモデル（t = 4, −3, 0 の3ペア）で ι² = id と ι f ι⁻¹ = f⁻¹ を
全点検査、通過。

## 帰結: 問C の正確な残り

定理 13.1 により、問C は次に**帰着**した:

> 計算可能な reverser を持つ f は、**軌道作用が対合な** reverser を
> 常に持つか。

γ が対合でない場合、γ は軌道空間上の置換で γ² が非自明。γ の
無限軌道 {…, C₋₁, C₀, C₁, …}（g が鎖の Z-族を順送りに反転していく
状況）では、対合的なペアリングに直すのに「一つおき」の選択
（パリティ選択）が要る。これは本プロジェクトで繰り返し現れた
「Z-族上の選択の計算不能性」と同じ形であり、次を予想する:

**予想 13.2（問C は否定的）.** 計算可能な reverser を持つが
強可逆でない計算可能置換が存在する。構成方針: 鎖の Z-族
{C_i}_{i∈Z} を用意し、g は C_i → C_{i+1} の反転順送りとする
（g は明示的に作れて計算可能）。免疫化型の要件で「族内のパリティを
計算可能に選ぶ手段」をすべて潰す。ただし ι は g の構造を無視して
よい（別のペアリングを発明できる）ので、要件は「任意の計算可能対合
ι が reverser でない」ことを直接扱う必要があり、定理 7.2 の
中心抽出＋Higman 補題 3.3 を族の言葉に持ち上げるのが筋。
（注意: doubling の教訓により、単純な鏡映対称を残すと ι が
存在してしまう。族を「一方向に無限」(i ∈ Z) にして鏡映の軸を
消すことが構成の要点になる見込み。）

## 問B の現在地（特徴づけの座標）

- 十分条件1: 軌道決定可能（定理 7.3）。
- 十分条件2: 軌道作用対合な計算可能 reverser の存在（定理 13.1。
  doubling の例はこの特殊例 γ = 対合・t ≡ 0）。
- 反例側: Higman 3.6 / 統合構成（reverser なし）。
- 開いた帯: reverser あり・軌道作用対合な reverser なし（予想 13.2 の
  住処）。ここが埋まれば問B は「強可逆 ⟺ 軌道作用対合な計算可能
  reverser を持つ」という**構造的特徴づけ**（右⟸左は自明、左⟹右は
  ι 自身が証人）で完結する。実は左⟹右は自明（ι の軌道作用は対合）
  なので、**問B の特徴づけは既に定理 13.1 で「強可逆 ⟺ 軌道作用
  対合な計算可能 reverser を持つ」として完結している**。開いて
  いるのは、この条件と「単に reverser を持つ」の分離（= 問C）のみ。
