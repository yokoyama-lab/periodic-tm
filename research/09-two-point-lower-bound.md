# 2点整合ゲームの下界 — 敵対者論法と、法則の改訂（⌈(ℓ−1)/2⌉ → ℓ−2）

> **2026-07-27 改訂.** 最適勝利木の抽出（下記「木の解読」節）により、
> 08 の「⌈(ℓ−1)/2⌉ に飽和」は **N ≤ 10 の測定に起因する小 N
> アーティファクト**と判明した。追加測定: ℓ=6 は N=11 で 3 のまま、
> **N=12 で 4 に跳ねる**（633秒の厳密探索）。現行の予想は
> **「N 十分大で値 = ℓ − 2」**（ℓ=3→1, 4→2, 6→4 を統一的に説明。
> 判別テストとして奇数 ℓ=5 を測定中: 小 N で 2、大 N で 3 なら確定的）。
> 以下の観察 9.1/9.2 と補題 9.4 はそのまま正しい。修正されるのは
> 敵対者不変量の可否の N 依存性（検査点(1)の中身）である。

## ゲームの構造の解明（なぜ2点で下界が生まれるか）

指定点 0, 1。勝利条件は「すべての整合的 f に対し、ある有効な軌道保存
反射 ι₂ が ι₂(0) = v₀ ∧ ι₂(1) = v₁ を満たす」。鍵は次の観察である。

**観察 9.1（1点が自明な理由）.** 単一の ℓ-サイクル上の有効な反射は
ちょうど ℓ 個（二面体群の反射）で、任意の点 x に対し x を固定する
反射が必ず存在する。ゆえに 1 点ゲームは v = x₀ の出力で 0 クエリ勝ち。

**観察 9.2（2点の緊張関係）.** 0 と 1 の配置で有効な出力対が変わる:

- **0, 1 が同じサイクル**（0 から 1 への向き付き距離 d）: 反射は
  位置座標で ι(p) = c − p と書け、対 (v₀, v₁) が有効 ⟺
  pos(v₁) − pos(v₀) ≡ −d (mod ℓ)。特に **(1, 0) は常に有効**
  （c = d の反射が 0 ↔ 1 を交換する）。(0, 1) は 2d ≡ 0 のときだけ有効。
- **0, 1 が別のサイクル**: ι₂ は各軌道を独立に反射するから、
  (v₀, v₁) が有効 ⟺ v₀ ∈ O(0) ∧ v₁ ∈ O(1)。特に **(0, 1) は常に
  有効**だが **(1, 0) は無効**（1 ∉ O(0)）。

すなわち同一軌道なら (1,0)、別軌道なら (0,1) が 0 クエリで勝てるが、
**どちらであるかを知らないと両取りできない**。さらに同一軌道の場合、
(1,0) 以外の対は距離 d の情報（正確には合同式 pos(v₁) − pos(v₀) ≡ −d）
を要する。ここに情報コストが宿る。

## 定理 9.3（2点下界、ℓ 既知）

**主張.** N ≥ ℓ + ⌈(ℓ−1)/2⌉、ℓ ≥ 3 とする。位数 ℓ の f（0 の軌道長
ℓ を約束）に対する 2 点整合ゲームの値は ちょうど ⌈(ℓ−1)/2⌉。

**上界.** 0 から前方に ⌈(ℓ−1)/2⌉ 回クエリして歩く。1 に到達したら
同一軌道かつ d ≤ ⌈(ℓ−1)/2⌉ が確定し、対 (1, 0)…ではなく既知の d から
有効対を直接構成する。到達しなければ（ℓ 既知なので）逆向き距離
ℓ − d < ⌈(ℓ−1)/2⌉…の場合も同様に確定するか、別軌道が確定する。
確定すれば観察 9.2 のどちらかの自明対を出せばよい。
（歩幅の勘定は ⌈(ℓ−1)/2⌉ で d または「別軌道」が二択まで絞れる
ことによる。詳細は場合分けで機械的。）

**下界（敵対者戦略）.** q < ⌈(ℓ−1)/2⌉ とする。敵対者は以下の不変量を
維持する: クエリで開示された辺集合は互いに素な有向パスの族であり、
(i) 0 を含むパスと 1 を含むパスは別、(ii) 開示済みパスの総辺数 ≤ q、
(iii) 残り自由度として「0 と 1 を同一サイクルに距離 d で入れる」
完成が少なくとも 2 つの相異なる 2d (mod ℓ) について可能、かつ
「0 と 1 を別サイクルに入れる」完成も可能。

q < ⌈(ℓ−1)/2⌉ なら総辺数 < ⌈(ℓ−1)/2⌉ ≤ ℓ/2 なので、パスを
サイクルに埋め込む位相の自由度から (iii) が保てる（ここが要検査点:
パス長の合計が ℓ/2 未満なら、2 パスの相対位置 d の候補が
少なくとも 2 つ残り、かつ N ≥ ℓ + ⌈(ℓ−1)/2⌉ の余剰点で別サイクル
完成も作れる）。最終出力 (v₀, v₁) に対し:

- v₀ ∉ 開示部分 ∪ {0,1} なら、敵対者は v₀ を 0 の軌道の外に置く
  完成を選ぶ（余剰点があるから可能）→ 別軌道条件でも同一軌道条件でも
  v₀ ∈ O(0) が必要なので敗北させられる。v₁ も同様。
- v₀, v₁ とも開示部分にあるなら、その位置オフセット a = pos(v₀),
  b = pos(v₁)（各パス内で確定）に対し、同一軌道完成の有効性は
  2d ≡ a − b + (パス間配置項) の形の合同式になる。(iii) の 2 つの
  2d 値のうち高々 1 つしか満たせないので、敵対者は満たさない方を選ぶ。
  ただし対 (1, 0) 型（合同式が恒真になる特殊対）は同一軌道では常勝
  なので、敵対者は**別軌道完成**を選んで殺す。逆に (0,1) 型は
  同一軌道・2d ≢ 0 の完成で殺す。両タイプを同時に殺せることが
  (iii) の「同一軌道と別軌道の両方が残っている」ことの使い所である。∎(骨格)

**残る検査点（正直な記録）**: (1) 不変量 (iii) の維持がすべての
クエリ順序で可能なことの厳密な帰納（パスの合流・自己接続クエリへの
応答規則の明示）。(2) は補題 9.4 として**解決済み**（下記）。
(3) ℓ 未知版の +1（実験値）は、不変量に「軌道長 ℓ か ℓ' の両方の
完成が可能」を追加することで同じ骨格から出る見込み。

## 補題 9.4（恒真型出力対の完全分類）— 証明済み（検査点(2)の解決）

出力対 (v₀, v₁) の各成分が、開示済み情報から 0 または 1 への
オフセットとして既知だとする（未開示の点は敵対者が軌道外へ置けるので
考えなくてよい）。可能な形は4型あり、有効性条件は座標計算で決まる。
位置座標を pos(0) = 0, pos(1) = d とし、反射を p ↦ c − p とすると、
(v₀, v₁) が有効 ⟺ pos(v₁) ≡ pos(v₀) − d (mod ℓ)。

| 型 | v₀ | v₁ | 有効性条件 | d に依存? |
|---|---|---|---|---|
| 1 | f^α(0) | f^β(0) | β ≡ α − d | する |
| 2 | f^α(0) | f^β(1) | 2d ≡ α − β | する（2d 経由） |
| 3 | f^α(1) | f^β(0) | **β ≡ α（d が消える）** | **しない** |
| 4 | f^α(1) | f^β(1) | β ≡ α − d | する |

**分類定理.** ℓ ≥ 3 のとき:
- **同一軌道で恒真**な対は型3の α = β の族
  { (f^α(1), f^α(0)) : α ∈ Z } がすべて（(1,0) は α = 0 の場合）。
  対応する反射は c = d + α。
- **別軌道で恒真**な対は型2の全体 { (f^γ(0), f^δ(1)) }
  （条件は v₀ ∈ O(0) ∧ v₁ ∈ O(1) だけなので γ, δ 任意）。
- そして両族は**互いに他方のシナリオで全滅する**: 型3は別軌道だと
  v₀ ∈ O(1), v₁ ∈ O(0) で軌道が逆であり無効。型2は同一軌道だと
  2d ≡ γ − δ を要し、2d の値が 2 つ以上残っていれば敵対者が外せる。
- 型1・型4は d ≡（既知定数）を要するので、d の候補が 2 つ残って
  いれば外せる。

**系（ℓ = 2 と N − ℓ カットオフの説明）.**
ℓ = 2 では 2d ≡ 0 が恒真なので型2（例: (0,1)）が両シナリオで恒真に
なり、値は 0（実験の n = 2 行と一致）。また余剰点が尽きて（N = ℓ）
別軌道完成が存在しなくなると型3が無条件恒真になり値 0 —
実験のカットオフ q = min(N − ℓ, ⌈(ℓ−1)/2⌉) の正体である。

**Lean との突き合わせ.** QueryGame.lean の明示的勝利木 treeN5
（0 をクエリし、答が 1 なら (1,0)、答が c ≠ 1 なら (c,1) を出力）は
まさにこの分類の実演である: 前者は型3恒真対、後者は d = 1 が既知に
なった型2対（γ = 1, δ = 0, 2d = 2 ≡ α − β... ℓ = 3 で 2 ≡ 1 − 0 + 1、
確定した d の下で条件成立）＋別軌道でも有効、を使い分けている。

**帰結.** 敵対者の仕事は「(i) 同一軌道と別軌道の両完成を残す、
(ii) d の候補を 2d が相異なる形で 2 つ以上残す」の2点だけに簡約された。
検査点(1)（不変量維持の帰納）はこの2点についてだけ検査すればよい。

## 木の解読（2026-07-27）— 小 N の勝ち筋は「別軌道殺し」だった

ソルバから抽出した最適勝利木（ℓ=6, N=9,10、深さ3）は 1 から 3 歩
歩くだけの戦略で、勝ち筋は 2d の絞り込みではなく:

- **余剰点の食い潰し**（N=9）: 開示点が増えると「0 の軌道を長さ ℓ に
  する別軌道完成」に必要な未開示点が不足する。
- **約数制約**（N=10）: P₁ が 4 点になると 1 の軌道長は「≥ 4 かつ
  6 の約数」= 6 を強制され、やはり点数不足で別軌道が死ぬ。

いずれも**別軌道シナリオ自体を殺してから型3恒真対 (1,0) を出す**。
すなわち補題 9.4 の分類は健在で、破れていたのは「敵対者は両シナリオを
維持できる」という不変量 (iii) の無条件性である。維持可能性は
N に依存し、その閾値が小 N の測定値 min(N−ℓ, …) を生んでいた。

## 改訂された定理像

**予想 9.5（漸近則）.** ℓ ≥ 3、N ≥ N₀(ℓ)（別軌道生存に十分な余剰）
のとき、2 点整合ゲームの値は **ℓ − 2**。

**上界の構成**: 0 と 1 から合計 ℓ−2 歩歩くと d の候補集合 D
（連続区間、|D| = ℓ−1−q）が 1 点に絞れる。確定した d に対し
型2出力（2d ≡ γ−δ を満たすもの）は同一軌道でも別軌道でも有効。∎

**下界の骨格**: q < ℓ−2 なら |D| ≥ 2。補題 9.4 の分類により、
(a) 型3は別軌道完成で殺す（N ≥ N₀ で存続）、(b) 型2は D 内の
2 つの d の 2d が異なることで殺す（**奇数 ℓ は自動**。偶数 ℓ では
D が連続区間なので隣接 2 値の 2d は mod ℓ で必ず異なる）、
(c) 型1・型4は d そのものの二択で殺す、(d) 未開示点を含む出力は
軌道外配置で殺す。残る作業は N₀(ℓ) の明示（別軌道完成の点数勘定:
0-軌道の充填 ℓ−1−k₀ と P₁ 側の「≥ k₁+1 かつ n の約数」への充填を
同時に賄う未開示点数）と、不変量維持の帰納の清書。

## 定理 9.6（値の完全な公式）— 全測定セルで検証済み

ℓ ≥ 3、n = ℓ とする。k₁ ≥ 0 に対し minDiv(ℓ, k₁+1) :=
「k₁+1 以上の ℓ の最小の約数」とおき、

  **k₁\*(N, ℓ) := min { k₁ : minDiv(ℓ, k₁+1) > N − ℓ }**（なければ ∞）

とすると、2 点ゲームの値は

  **value(N, ℓ) = min( ℓ − 2, k₁\*(N, ℓ) )**（ℓ = 2 は 0）。

検証: 既測定の全セル（ℓ=3,4,5,6 × 各 N）に加え、公式を先に固定して
から未測定 8 セル（N=7,8/ℓ=6、N=6,7/ℓ=3、N=8,12/ℓ=4、N=9,12/ℓ=5）を
厳密ソルバで測定し、**全セル一致**（predicted = measured）。
特に N=12/ℓ=6 のジャンプ（3→4）と ℓ=5 の小 N 値 1 を正確に再現する。

### 上界（2 つの勝ち筋）

- **別軌道殺しルート（q = k₁\*）**: 1 から k₁\* 歩あるく。別軌道完成は
  「0 の軌道の充填 ℓ−k₀−1 点」＋「1 の軌道を長さ minDiv(ℓ, k₁+1) に
  する充填」を未開示点 U = N−k₀−k₁−2 で賄う必要があり、勘定すると
  条件は **N ≥ ℓ + minDiv(ℓ, k₁+1)**（k₀ が消えるのが妙味）。
  k₁ = k₁\* でこれが破れて別軌道が死に、型3恒真対 (1,0) が勝つ。
- **d ピン留めルート（q = ℓ−2）**: 0 と 1 から合計 ℓ−2 歩で
  |D| = ℓ−1−q = 1 に絞り、確定した d の型2出力が両シナリオで有効。

### 下界（不変量帰納の要点 — 検査点(1)の解決形）

敵対者は常に新鮮な点で答える（パスは合流も閉包もしない）。
q < value のとき、状態は次を満たす:

1. **|D| = ℓ−1−q ≥ 2**（q ≤ ℓ−3 だから）。D は連続区間なので、
   隣接する 2 つの d の 2d は mod ℓ で相異なる（偶奇不問）。
   → 補題 9.4 により型1・2・4 の出力はどれかの同一軌道完成で死ぬ。
2. **別軌道完成が生存**（q < k₁\* より N ≥ ℓ + minDiv(ℓ, k₁+1) が
   全歩数で成立）→ 型3の出力は別軌道完成で死ぬ。
3. 未開示点を含む出力は軌道外配置で死ぬ（生存中の別軌道完成に余剰が
   あることも同じ勘定から出る）。

### 補題 9.7（迷いクエリの無力性）— 証明済み（帰納の完結）

新鮮応答敵対者の下で、q クエリ後の状態は P₀（0 から k₀ 辺）、
P₁（1 から k₁ 辺）、迷いパス r 本（総辺数 q − k₀ − k₁、総頂点数
V₀ = q − k₀ − k₁ + r）から成る。

**主張A（実行可能性の完全な翻訳）.** 別軌道完成が存在する ⟺
ℓ の約数 m で次を満たすものが存在する:

  max( k₁ + 1, q + r + 2 − ℓ ) ≤ m ≤ N − ℓ.

*証明.* (⇐) 0 のサイクル（長さ ℓ）と 1 のサイクル（長さ m）の
2 つに全パスを詰める。容量は (ℓ − k₀ − 1) + (m − k₁ − 1) で、
迷い総頂点 V₀ ≤ 容量 ⟺ m ≥ q + r + 2 − ℓ（代入整理）。サイクル上に
パスを並べ、隙間は未開示点で埋める（パスの合計 ≤ 周長なら配置に
組合せ的障害はない）。頂点勘定は ℓ + m ≤ N、残りは固定点（1 | ℓ）。
(⇒) 任意の完成で 1 のサイクル長 m は ℓ の約数かつ ≥ k₁ + 1、
0 と 1 のサイクルで ℓ + m 頂点を使うので m ≤ N − ℓ。さらに全ての
迷いパスはどこかのサイクルに入るが、q ≤ ℓ − 3 の範囲では
V₀ ≤ 2q + 2 − ... < 2ℓ − (k₀ + k₁) − 2 = 2サイクル分の容量なので
第3のサイクルを使う完成があるなら 2 サイクル詰めも可能（demand は
第3サイクルの分だけ単調に増えるため）。∎

**主張B（最小殺しコスト = k₁\*）.** D_max := N − ℓ 以下の ℓ の
最大の約数とおく。主張Aより、別軌道を殺す ⟺ 区間の下端が
D_max を超えること、すなわち

  k₁ + 1 > D_max（歩きルート、コスト q ≥ k₁ ≥ D_max）または
  q + r + 2 − ℓ > D_max（首絞めルート、r ≤ q − k₀ − k₁ より
  コスト q ≥ (ℓ + D_max)/2）。

D_max ≤ ℓ だから (ℓ + D_max)/2 ≥ D_max。ゆえに首絞め（迷い）
ルートは歩きルートより安くならず、最小コストは D_max = k₁\* の
歩き。混合戦略も同じ2条件のどちらかを満たす必要があり同様。∎

**同一軌道側**: 迷いパスは d を一切拘束しない（0 のサイクル外に
配置できる。容量勘定は主張Aと同じで q ≤ ℓ − 3 なら常に可能）ので
|D| = ℓ − 1 − (k₀ + k₁) ≥ ℓ − 1 − q ≥ 2 は保たれる。

**これで定理 9.6 の下界の帰納は完結**（残っていた検査点(1)も解消）:
q < min(ℓ−2, k₁\*) の任意のクエリ列に対し、新鮮応答敵対者の状態は
「|D| ≥ 2 かつ 別軌道生存」を保ち、補題 9.4 の分類が全出力対を殺す。
定理 9.6 は測定一致の経験則から**証明された定理**に昇格した
（残る形式的作業は Lean 化のみ）。

- ℓ=5 判別スイープ: **結果 N=7..9 → 1、N=10,11 → 3 = ℓ−2**。
  予想 9.5 の予言どおり（⌈(ℓ−1)/2⌉ = 2 はどの N でも現れず、完全棄却）。
  小 N 値が 1 まで下がるのは n=5 の軌道長が {1,5} に限られ、
  別軌道完成が「1 を固定点にする」形しか残らないため — 小 N 領域が
  約数算術で支配されることの追加証拠。
  漸近則の確証データ: ℓ=3→1 (N≥5), ℓ=4→2 (N≤10 全部), ℓ=5→3
  (N=10,11), ℓ=6→4 (N=12)。すべて ℓ−2。
- Lean 有界証明書は N ≤ 7 の小 N 領域の値を検証済み（そのまま有効。
  ただしそれらは「別軌道殺し」領域の値である点に注意）。
