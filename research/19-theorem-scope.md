# 定理9.6 はどこで実質を持つか — 約束の非空性

2026-08-22 夜間 autoresearch。機械化された定理9.6（`gameValue_eq`）に対する
**空虚性（vacuity）の監査**と、その結果の機械化。

## 動機

`gameValue_eq` は

```
gameValue N ℓ = min (ℓ − 2) (k₁*(N, ℓ))
```

を `2 ≤ N`・`2 ≤ ℓ` の下で主張する。**`ℓ ≤ N` という仮定が無い。**

ゲーム値は「勝利木が存在する最小の深さ」であり、勝利
（`WinsAt n ℓ a b t := ∀ f, Valid n ℓ a f → Runs a b t f`）は
約束を満たす全ての `f` にわたる**全称命題**である。したがって
**約束を満たす `f` が 1 つも無ければ、どんな木も空虚に勝つ**。
上下界の証明が sorry 0 で通っていても、それだけでは
「主張に中身があるか」は分からない。

これは機械証明の受け入れ判定で最初に問われる点なので、
今夜これを確定させた（層1 昇格の判断材料）。

## 結論

約束 `validPerms N ℓ ℓ 0`（`f^ℓ = 1` かつ `0` の軌道長がちょうど `ℓ`）は

```
非空  ⟺  0 < ℓ ≤ N
```

**したがって定理9.6 が実質を持つのはちょうど `0 < ℓ ≤ N` の範囲**であり、
`ℓ > N` では空虚に真になるだけである。

### `ℓ > N`（空虚域）では 2 つの独立な理由で値が 0 になる

1. **閉形式そのものが崩壊する。** `Kills N ℓ k` の定義は
   `∀ m ≤ ℓ, k+1 ≤ m → m ∣ ℓ → N − ℓ < m`。`N ≤ ℓ` では自然数減算により
   `N − ℓ = 0` なので、`m ≥ 1` に対して `0 < m` は常に成り立ち、
   `Kills N ℓ 0` が（空虚にではなく文字通り）成立する。よって
   `k₁* = 0`、`min (ℓ−2) (k₁*) = 0`。→ `k1Star_eq_zero_of_le`
2. **約束が空なので木が要らない。** `Valid ℓ ℓ 0 f` は軌道長 `= ℓ` を
   要求するが、軌道は `Fin N` の部分 Finset なので濃度は `N` 以下。
   `N < ℓ` では満たす `f` が無く、深さ 0 のダミー葉が空虚に勝つ。
   → `gameValue_eq_zero_of_lt`

2 つは独立に成り立ち、たまたま同じ値 0 に落ちる。**式が正しいのは
偶然ではなく自然数減算の切り捨てのおかげ**であって、ここは
「定理が成り立っている」と言うべき箇所ではない。

### `ℓ = N` は空虚ではない（値 0 は本物）

`k1Star_eq_zero_of_le` は `N ≤ ℓ` 全体で成り立つので `ℓ = N` でも
`k₁* = 0`、値は 0。しかし `ℓ = N` では約束は**非空**（`N` 巡回置換が証拠）
なので、この 0 は実質のある値である。厳密ソルバの測定
`(4,4,0) (5,5,0) (6,6,0)` と一致する。
**空虚域は `ℓ > N` のみで、`ℓ = N` はその境界の内側**。

## 紙証明への提案（research/09）

定理9.6 の主張に **`ℓ ≤ N` を明示の仮定として書く**ことを勧める。
現状の紙の記述は「`0` の軌道長が `ℓ`」という約束から `ℓ ≤ N` を
暗黙に読ませているが、機械化された主張はその仮定なしでも通ってしまい、
`ℓ > N` の範囲では内容が無い。仮定を書けば、定理の適用範囲が
そのまま実質の範囲と一致する。

なお `ℓ ≤ N` を仮定に足しても既存の証明は一切変わらない
（`gameValue_eq_nonvacuous` は `gameValue_eq` をそのまま使っている）。
純粋に主張の明確化である。
