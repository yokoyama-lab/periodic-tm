# 下界の撃墜設計 — 同一軌道側の容量勘定の隙と、その完全な埋め方

2026-08-10 深夜、autoresearch。research/17 の修正方針（付け替え τ の輸送）を
実装する過程で、**紙証明（research/09）の「同一軌道側: 容量勘定は主張Aと
同じで q ≤ ℓ−3 なら常に可能」という一行が3つの実質的な隙を隠している**
ことが分かった。ここに完全な設計を残す。実装は
`TwoPointRelabel.lean`（済）・`TwoPointConcrete.lean`・
`TwoPointTransport.lean`・`TwoPointSameCycle.lean`（M5、未完）。

## 隙1: research/17 の `Strategy N` 案は定義できない

17 は「allocation 順の具体戦略 `freshStrategy : Strategy N` を定義する」と
書いたが、`Strategy` の答え関数は `AdvState → Fin N → Fin N` であり
**新鮮な答えを計算できない**。新鮮点は「過去に使った具体的な点」を
避ける必要があるが、迷いパスの開始点はアルゴリズム側が任意の点を
クエリして作るので、使用済み集合は抽象状態 `AdvState` に写らない
（カウンタ方式 `answer s x := ofNat (vertexCount s)` は、アルゴリズムが
先回りして将来の答え候補の点をクエリすると衝突する）。

**修正**: 具体頂点リストを持つ状態 `ConcState`（`p0`・`p1`・
`strays : List (Fin N × List (Fin N))`）で対局し（`TwoPointConcrete`）、
葉で `extendPerm`（対応リストから置換を延長; `TwoPointRelabel`）により
グループ順ラベル → 実頂点の付け替え τ を作る（`TwoPointTransport`）。
重要な発見: **完成と対局の一致（Agrees）には不変量が一切不要**
（クエリされた辺は必ず状態に記録されるので、「終状態の開示辺を全て
拡張する」だけで一致が出る）。不変量（頂点の相異なり）が要るのは
τ の単射性と頂点数の勘定だけ。

## 隙2: 同一軌道完成は迷いパスを全部は載せられない（溢れ）

`TwoPointAdversary.sameCycleVerts` は全ブロックを 0-1 サイクルに入れる
構成で、長さの制約は `vertexCount + g + r = ℓ`。しかし領域内でも
`vertexCount` は `2 + q + r` まで育ち、`ℓ ≥ q + 3` しかないので
**q ≥ 1 で既に入り切らない状態が存在する**（例: N=6, ℓ=4, 迷い1本
2頂点, q=1 は領域内だが 4 < 6）。つまり既存の
`sameCyclePerm_isCompletion` は下界の帰納には十分でない。

**修正（2サイクル構成 + 詰め込み）**: 主張Aの `buildPerm` と同型の
2 サイクル構成にする。
- サイクルA（長さ ℓ）: `0 :: P₀ ++ gap(g) ++ 1 :: P₁ ++ bA.flatten ++ tail(e)`
- サイクルB（長さ m₀）: `bB.flatten ++ fillB`、`m₀ | ℓ` は
  `¬Kills` の証人（`q+1 ≤ m₀ ≤ N−ℓ`）
- 分割 (bA, bB) は 2 ビン詰め。**`two_bin_pack` の条件を 1 だけ精密化**
  （`sum + max ≤ c₀ + c₁ + 1` で十分。貪欲の拒否時解析を見直すだけ）
  すると、既存の `capacity_ineq`（`sum+max ≤ (ℓ−1−k₀)+(m−1−k₁)`）が
  ちょうど `c₀ = ℓ−3−k₀−k₁`（= g=1 のときのA容量）、`c₁ = m₀` の
  条件式に一致する。精密化しないと N=6/ℓ=4/迷い1本の領域内状態で
  詰め込みが出ない（実際に踏んだ）。
- **距離 d と d+1 は同じ分割を使い**、gap を 0 → 1 に増やし tail を
  1 減らす。すると (i) 迷いAの頂点の「d からの相対位置」
  `pos = d + (1 + k₁ + j)` が両完成で同じ（型4系の撃墜に乗る）、
  (ii) サイクルAが使う充填ラベル集合 `[vc, vc+g+e)` とサイクルBが
  両完成で**完全に一致**する（B は文字通り同一）。

## 隙3: 未開示点の撃墜は「軌道外配置」だけでは閉じない

紙は「未開示点を含む出力は軌道外配置で殺す」（09）とするが、
**軌道外の余剰が無い角がある**: fillB = 0 かつ spare = N−ℓ−m₀ = 0 は
領域内で実現する（N=6, ℓ=4, 迷い1本: 未開示2点が全部サイクルAの
充填に入る）。このとき未開示点は必ず 0 の軌道上に乗る。

**修正（資源の三択）**: 未開示ラベルの置き場は τ の自由度
（`extendPerm` の ext リスト）で選ぶ。領域内では
`N − vertexCount ≥ 2`（∵ `N ≥ ℓ + m₀ ≥ 2q+4`、`r ≤ q`）なので、
次の資源のどれかが必ずある:
1. **軌道外ラベル**（fillB・spare・bB の頂点）: 置いた成分が
   `∉ O(0) ∧ ∉ O(1)` になり、その成分だけで撃墜。
   存在条件 fillB + spare ≥ 1。
2. **共通尾部ラベル** `w = vc + (g+e) − 1`: 両完成で位置 ℓ−1
   （g=0 の tail は e+1 個、g=1 は e 個なので、e(g=1) ≥ 1 なら両方の
   末尾が w）。位置が固定されるので型1/2系の合同式撃墜に乗る。
   存在条件 e(g=1) ≥ 1。1 と 2 は `N − vc ≥ 2` からどちらかが成立
   （fillB+spare = 0 ⇒ g+e = N−vc ≥ 2 ⇒ e ≥ 1）。
3. **別軌道完成の配置自由度**: (U,U)（両成分未開示）は 1・2 だけでは
   閉じない（実例: N=6, ℓ=4, k₀=0 で合同式が両距離とも成立しうる）。
   別軌道完成の未開示ラベルの内訳 n₀（0側充填）・n₁（1側充填）・
   spare' は n₀+n₁+spare' ≥ 2 を満たすので、
   n₁ ≥ 1 なら v₀ ↦ 1側充填（∉ O(0)）で撃墜、
   n₁ = 0 なら v₁ ↦ 任意の未開示ラベル（全部 ∉ O(1)）で撃墜。
   これには `formula_to_completion` の**強化版**（充填の内訳を
   露出する）が要る。

## 葉の場合分けの完全表

成分の分類: Z（0/P₀上: 位置 α は d に依らない）、O'（1/P₁/迷いA:
位置 d + a）、U（未開示）、SB（迷いB: 両軌道の外）。
資源: T = 共通尾部（位置 ℓ−1）、X = 軌道外ラベル、D = 別軌道完成。

| (v₀, v₁) | 撃墜 |
|---|---|
| (Z,Z) | 2距離・型1 |
| (Z,O') | 2距離・型2 |
| (O',Z) | D: v₁ ∈ O(0) ⇒ v₁ ∉ O(1) |
| (O',O') | 2距離・型4 |
| (SB,·)/(·,SB) | 同一軌道完成で当該成分が軌道外 |
| (Z,U) | X: v₁ 軌道外／T: v₁ ↦ w、型1（β=ℓ−1 固定） |
| (U,Z) | X／T: v₀ ↦ w、型1（α=ℓ−1 固定） |
| (O',U) | X／T: v₁ ↦ w、合同 β≡a は a ≤ ℓ−3−k₀ < ℓ−1 で両距離とも破れる |
| (U,O') | X／T: v₀ ↦ w、型2（α=ℓ−1、2d 系） |
| (U,U) | X: v₀ 軌道外／D: n₁≥1 なら v₀↦1側、n₁=0 なら v₁↦未開示（∉O(1)） |

注意: (O',Z) の D 撃墜は v₀ の側を見ない（迷いAの頂点は別軌道完成では
どちらの軌道に入るか統制できないため、**v₁ ∈ O(0) 側で殺す**のが正しい。
v₀ が 1/P₁ のときだけは v₀ ∉ O(0) でも殺せるが、場合分けを増やさない）。
