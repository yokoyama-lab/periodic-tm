# 課題2 実験: 軌道保存二対合分解のクエリ複雑性の厳密測定 (2026-07-26)

`02-complexity.md` の「実験計画」の実施。SAT ではなく純 Python の厳密
ミニマックス探索（状態の正規化＋メモ化）で、小パラメータの最悪ケース
適応クエリ数を**厳密に**計算した。コード: [`query_lb_search.py`](query_lb_search.py)
（`python3 research/query_lb_search.py` で表を再現、`--selftest` で検証）。

## 実装したゲームの正確な定義

固定: ドメイン [N]、位数 n（f^n = id）、指定入力 x₀ = 0。
オプションの約束: 「x₀ の軌道長はちょうど ℓ」。

- アルゴリズムは点 x を適応的にクエリし f(x) を得る。
- 敵対者は「f^n = id なる [N] 上のある置換（＋約束）と整合する」限り
  自由に答える（整合性は f^n = id の厳密な充足可能性判定で毎手チェック。
  既知部分は道と閉路の非交和になり、道＋未接触点を n の約数長の閉路に
  組み上げられるかを厳密に判定する）。
- q 回のクエリ後にアルゴリズムが値を出力。**勝利条件**: トランス
  クリプトと整合する**すべての** f に対し、**ある**有効な軌道保存反転
  ι₂（各 f-軌道を自分自身に写し、ι₂² = id、ι₁ := f∘ι₂ も対合）が
  存在して指定点での値が出力と一致する。
- 求める量 = ミニマックス値（アルゴリズム最善・敵対者最善の最小 q）。

勝利判定は整合する f の**全列挙**（f^n = id と約束で枝刈りした
バックトラック）＋達成可能出力集合の共通部分で厳密に行う。状態は
指定点以外のラベル張り替えで正規化してメモ化（未接触点は交換可能、
既知グラフは道・閉路形状の多重集合で表現）。

2 変種を測定:

- **ゲーム A**（課題文どおり・1点）: 出力 v、勝利 ⟺ ∀f ∃ι₂. ι₂(0) = v。
- **ゲーム B**（大域整合性の最小プロキシ・2点）: 出力 (v₀, v₁)、勝利 ⟺
  ∀f ∃**単一の** ι₂. ι₂(0) = v₀ ∧ ι₂(1) = v₁。

## 主結果 1: ゲーム A は完全に自明化する（q = 0、全パラメータ）

**補題（総当たりで検証済み、N ≤ 5・n ∈ {2,3,4,6} の全 f）.**
ℓ-閉路 (a₀ … a_{ℓ−1}) 上の有効な ι₂ の制限は、ちょうど ℓ 個の二面体的
反転 ι(a_i) = a_{(m−i) mod ℓ}（m = 0..ℓ−1）であり、軌道ごとに独立に
選べる。

m = 0 の反転は a₀ を固定する。よって **v = x₀ という出力が任意の f で
常に有効**であり、ゲーム A の値は 0 クエリ（約束の有無・全 N, n, ℓ で。
N = 4, 5 は全列挙による直接検証でも 0 を確認、`--selftest`）。

**含意**: 「1 評価あたり ⌈(ℓ−1)/2⌉」という下界予想は、
「単一入力で ∃ι₂ を後出しで選んでよい」定式化では**偽**（0 で計算
できる）。反転中心 m の自由度（障害Aの軌道内版）が単一点の値を完全に
非拘束にするため。下界が立つとすれば、ι₂ が**複数入力にわたり同一**で
あること（大域整合性）を使う定式化が不可欠 — これが次のゲーム B。

## 主結果 2: ゲーム B（2点・単一 ι₂）の厳密値

q(A) は全行 0 なので省略。q(B) の表（`*` = 約束なし。全セル数秒以内、
タイムアウトなし）:

| N | n=2 | n=3 (ℓ=*, 3) | n=4 (ℓ=*, 2, 4) | n=6 (ℓ=*, 2, 3, 6) |
|---|-----|--------------|-----------------|--------------------|
| 4 | 0   | 1, 1         | 2, 0, 0         | 1, 0, 1, —         |
| 5 | 0   | 1, 1         | 2, 0, 1         | 1, 0, 1, —         |
| 6 | 0   | 1, 1         | 2, 0, 2         | 3, 0, 1, 0         |
| 7 | 0   | 1, 1         | 2, 0, 2         | 4, 0, 1, 1         |
| 8 | 0   | 1, 1         | 2, 0, 2         | 4, 0, 1, 2         |
| 9 | 0   | 1, 1         | 2, 0, 2         | 4, 0, 1, 3         |

（ℓ = 1 は全て 0 で省略。n = 2 は ι₂ = id が常に有効なので恒等的に 0。）

### 観測されたパターン

**約束つき（ℓ 固定）— 予想値に正確に一致（十分な余白があれば）:**

    q(B, ℓ 固定) = min( N − ℓ,  ⌈(ℓ−1)/2⌉ )     （測定範囲で例外なし）

- ℓ = 3: 1 = ⌈2/2⌉、ℓ = 4: N ≥ 6 で 2 = ⌈3/2⌉、ℓ = 6: N = 9 で
  3 = ⌈5/2⌉。**飽和値はまさに ⌈(ℓ−1)/2⌉** — 予想の値そのもの。
- N − ℓ 側の切断は小 N アーティファクト。特に N = ℓ では軌道 =
  全ドメインが確定し、出力 (1, 0)（0 と 1 を入れ替える反転は同一軌道
  なら常に存在: m = j）で 0 クエリ勝ちできる。敵対者の力の源は
  「0 と 1 が同一軌道か否か・相対位置がどれか」の曖昧さであり、
  それには N − ℓ 個の「逃げ場」が要る。

**約束なし — 予想値を 1 超えることがある:**

- n = 3: 1、n = 4: 2 = ⌈3/2⌉、しかし **n = 6, N ≥ 7: 4 > ⌈5/2⌉ = 3**。
  軌道長 ℓ 自体の曖昧さ（ℓ ∈ {1,2,3,6}）が追加で約 1 クエリ分の力を
  敵対者に与える。⌈(ℓ−1)/2⌉ は「ℓ 既知」の複雑性としてのみ正しい。

### 解釈

- 予想 2.3 の足がかり「軌道保存的分解は ⌈(ℓ−1)/2⌉ クエリ」は、
  **1 点評価では成立しない**（主結果 1）が、**2 点の大域整合性を課した
  途端に厳密に ⌈(ℓ−1)/2⌉ で飽和する**（主結果 2）。下界証明の敵対者
  論法は「複数入力での ι₂ の同一性」を明示的に使う形で書くべき、
  という設計指針が実験から裏づけられた。
- 直観: 同一軌道上で ι₂(0) を決めると反転中心 m が確定し、ι₂(1) は
  相対位置 j に依存する。0 と 1 の双方から前向き走査して「中間で
  出会う」戦略が上界 ~ℓ/2 を与え、敵対者は出会うまで軌道の閉じ方を
  遅延できる — 測定値はこの両側が一致することを示す。

## 注意（正直な限界）

- **小 N アーティファクト**: N ≤ ℓ + 2 程度では q が N − ℓ に切断され
  る。漸近則の主張は「飽和後の値」（ℓ = 3, 4 は複数 N で安定、ℓ = 6 は
  N = 9 で飽和値に到達）に基づく。追試として N = 10, n = 6 を実測:
  ℓ = 6 固定で q = 3（11 秒）、約束なしで q = 4（23 秒）— いずれも
  N = 9 と同値で、飽和を支持する。
- 公式 min(N − ℓ, ⌈(ℓ−1)/2⌉) は測定 6 × 4 グリッドからの補間であり
  証明ではない。約束なしの「+1」も n = 6 の 3 点のみの観測。
- ゲーム B は大域整合性の**最小**プロキシ（2 点）。予想 2.3 本体
  （全入力で有効なオラクル機械・1 評価あたり Ω(n)）とはなお距離が
  ある。k 点版（k = 3 で複数軌道間の干渉が出るか）が自然な次段階。
- タイムアウトは発生せず（セル上限 150 秒、実測は最大でも約 3 秒）。
  探索・整合性判定・勝利判定はすべて厳密（ヒューリスティックなし）。
  反転補題のみ構造的に使用し、N ≤ 5 で総当たり検証済み
  （`--paranoid` でゲーム A も全列挙再検証可）。
